# 主题音乐（Theme Music）

适用于 Unraid 6.12+ 的独立 WebGUI 音乐播放器。

## 核心能力

- 本地目录与 Navidrome/OpenSubsonic 双音源
- 仪表盘音乐卡片与全站音乐胶囊，单一音频宿主跨刷新保持播放
- PC/手机独立运行模式、音量、自动播放、随机与循环设置
- 本地大曲库低优先级单实例后台完整索引，重复刷新不叠加扫描
- 曲库搜索/排序与分段渲染、封面、同步歌词、普通歌词和跨页续播
- 歌词可按曲目提前/延后 0.5 秒，偏移持久保存并支持手动归零
- 本地磁盘唤醒与 SMB/NFS 远程挂载就绪自动分流
- 歌词与下载封面固定写入歌曲同目录，不占用启动盘动态缓存
- SHA256 差异 OTA、历史版本回滚和离线 flash 恢复

## 入口

安装后前往：**设置 → 用户偏好 → 主题音乐**

卡片与胶囊是否显示只由总开关和电脑/手机运行模式决定。

全站模式的宿主仅在用户点击播放时创建，并始终复用固定窗口；刷新与内部切页不会新建标签。离开 Tower 自动暂停，返回后自动恢复，关闭 Tower 后结束播放。

## 数据与安全

Navidrome 密码独立保存为 `0600`，不会写入普通配置、浏览器或日志。插件不会上传音乐文件、播放记录或账号凭据。
