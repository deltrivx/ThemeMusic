# 主题音乐（Theme Music）

适用于 Unraid 6.12+ 的独立 WebGUI 音乐播放器。

## 核心能力

- 本地目录与 Navidrome/OpenSubsonic 双音源
- 仪表盘音乐卡片与全站音乐胶囊
- PC/手机独立运行模式、音量、自动播放、随机与循环设置
- 曲库搜索/排序、封面、同步歌词、普通歌词和跨页续播
- 播放前磁盘唤醒、远程挂载等待、低负载缓存
- SHA256 差异 OTA、历史版本回滚和离线 flash 恢复

## 入口

安装后前往：**设置 → 用户偏好 → 主题音乐**

卡片与胶囊是否显示只由总开关和电脑/手机运行模式决定。

## 数据与安全

Navidrome 密码独立保存为 `0600`，不会写入普通配置、浏览器或日志。插件不会上传音乐文件、播放记录或账号凭据。
